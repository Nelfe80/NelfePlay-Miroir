三步，电脑或自己的机台都行

Windows 电脑和个人机台的体验是一样的，不需要专门的场馆。

  1. 01

    创建你的档案

    一个邮箱和一条登录链接。昵称就是你在排行榜上的身份，你的游戏和纪录都在这里。

  2. 02

    准备你的机器

    RetroBat、APIExpose，然后与账号绑定。引导会从你停下的地方继续，已完成的步骤会跳过。

  3. 03

    开玩，进入排行榜

    成绩带着签名和时间送出，回放随后生成，你的世界排名也会出现。

玩法

每款开放的游戏提供以下一种或多种模式。可在 Games 页面筛选，一切都从你的机器上开始。

Scoring

你的对局分数经过认证，进入全球排名。1CC：一个币通关。1LC：第一条命的最高分。每个分数都带签名和回放。

查看全部游戏

速通与幽灵

一个关卡、一个首领或整个游戏，从所有人相同的起点按帧计时。你的纪录和世界纪录会以幽灵形式与你同跑。每个项目都有自己的计时排行榜。

查看全部游戏

Mass Run

实时竞速：数十名玩家在同一关卡、同一起点，各自在自己的机器上比赛。其他选手以其头像的颜色出现在屏幕上。每款游戏都有自己的评分；比赛不做认证。

查看全部游戏

Challenges

规则既定的挑战，例如只用一种武器或某种限制，从起点坚持到终点。每个挑战都有自己的计时排行榜；挑战不做认证。

查看全部游戏

速通、Mass Run 和挑战都从 EmulationStation 的 Challenges & Speedruns 标签页开始。

经过签名、永久锚定的分数

匿名徽章

徽章上只有一个标识和一个昵称。机台上、徽章上、这个排行榜上，都不会出现个人信息。

场馆签名

每一批分数在公开前，都用场馆自己的密钥签名。「已认证场馆」说的就是这件事。

锚定在比特币

分数日志通过 OpenTimestamps 加上时间戳。任何人都能验证一条纪录事后没有被改动。

挑战

  • 1CC（One-Credit Challenge）：游戏的任一模式，只用一个币。✓1CC（One-Credit Clear）：用这一个币打通游戏。
  • 1LC（One-Life Challenge）：从头到尾只用一条命。
  • 1CC MULTI（One-Credit Challenge, multiplayer）：多人同局，每人一币。
  • 1LC MULTI（One-Life Challenge, multiplayer）：多人同局，每人第一次失去生命前的得分。
  • 1CC MM（One-Credit Challenge, Multi Modes）：每款游戏的 1CC 与特殊模式合计。
  • SPEEDRUN：每个项目（一个关卡、一个首领、整个游戏）都有自己的时间排名。
  • CHALLENGE：按规定规则（一种武器、一项限制）从起点到终点的挑战，每项都有自己的时间排名。 挑战不经认证。
  • Mass Run: live races, dozens of players on the same level from the same start. Each game has its rating per format; the top ten of each game’s permanent Mass Speedrun leaderboard score points. Races are not certified.

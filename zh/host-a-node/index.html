为什么需要节点

始终在线

主服务器宕机时，访客会被引导到镜像：排行榜、游戏页面、玩家卡片和纪录依然可以访问。

离玩家更近

每个镜像服务其所在地区：页面和回放加载更快。

不涉及个人信息

节点只接收已经公开的内容。电子邮箱、密码和账户数据绝不会离开主服务器。

需要准备

  • ✓64 位 Linux（x64 或 ARM64），使用 Docker 或直接安装

  • ✓根据角色准备磁盘空间（镜像需要几 GB）
  • ✓开启自动更新
  • ✓一个已验证电子邮箱的 NelfePlay 账户

托管方章程

  • ✓不修改节点提供的任何内容。
  • ✓保持副本最新：节点会自动同步，请勿阻止。
  • ✓不利用或转售经过的数据。
  • ✓连接日志保持最少，且保存时间不超过要求。
  • ✓离开网络前提前告知。

加入流程

  1. 01

    申请

    填写下方表格。

  2. 02

    审核

    团队会审核你的申请并回复你。只有获批准的托管方才能加入网络。

  3. 03

    注册码

    你会收到一个与 NelfePlay 账户绑定的一次性代码。

  4. 04

    安装

    使用你的代码，一条命令或 Docker 镜像即可完成安装。节点会自行测试。

  5. 05

    正式上线

    你的节点会获得名称（例如 www3.nelfeplay.com）和证书，并以较小的权重加入网络，权重随可靠性提升。服务器列表不公开：与其他已批准的托管方一样，你可以在“我的服务器”中查看。

✓

可验证的镜像

网站的每个版本都由 NelfePlay 签名，节点会拒绝任何被篡改的副本。镜像之间也会互相检查：每小时，每个镜像都会像普通访客一样读取随机抽中的另外两个镜像，并将它们提供的内容与签名版本比对。NelfePlay 会核实每一个被报告的差异；篡改所提供内容的镜像将被移出网络。

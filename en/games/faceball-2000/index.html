The story of the game

The why and the how

Faceball 2000 is the name of the Game Boy version of MIDI Maze, a networked first-person shooter maze video game developed by Xanth Software F/X for the Atari ST and released in 1987 by Hybrid Arts. The world animates smoothly as the player turns, instead of only permitting 90 degree changes of direction. Using the MIDI ports on the Atari ST, the game is said to have introduced deathmatch combat to gaming in 1987, and it predated the LAN party concept by several years.

How it was made

The original MIDI Maze team at Xanth Software F/X consisted of James Yee as the business manager, Michael Park as the graphic and networking programmer, and George Miller writing the AI and drone logic. A Game Boy version was developed by Xanth and published in 1991 by Bullet-Proof Software. James Yee, owner of Xanth, had the idea of porting the 520ST application to the Game Boy. George Miller was hired to rewrite the AI-based drone logic, giving each drone a unique personality trait.

What makes it unique

The game area occupies only roughly a quarter of the screen and consists of a first-person view of a flat-shaded maze with a crosshair in the middle. All players are shown as Pac-Man-like smiley avatars in various colors. Bullets are represented as small spheres. On Game Boy, the version allows two players with a Game Link Cable, or up to four players with the Four Player Adapter. In the original, the game is started by a designated master machine, which sets rules, divides players into teams, and selects a maze.

Its influence

It is often rumored that the Game Boy version would allow up to 16 players by daisy-chaining Four Player Adapters, which is not the case. According to programmer Robert Champagne, the original game's code does contain a 16-player mode, but it required a special adapter planned to be bundled with the game. The mode was announced in the April 1991 issue of Nintendo Power; however, Nintendo did not allow the adapter's release. A Super NES version was released in 1992, supporting two players in split-screen, with completely different graphics and music by George The Fat Man Sanger. Riverhill Soft released Game Gear and PC Engine CD-ROM versions in Japan.

Challenges

  • 1CC (One-Credit Challenge): a single credit, in one of the modes of the game. ✓1CC (One-Credit Clear): the game finished on that credit.
  • 1LC (One-Life Challenge): a single life, from start to finish.
  • 1CC MULTI (One-Credit Challenge, multiplayer): a single credit each, several players in the same run.
  • 1LC MULTI (One-Life Challenge, multiplayer): each player's score up to their first life lost, several players in the same run.
  • 1CC MM (One-Credit Challenge, Multi Modes): the 1CC of each game and its special modes, added together.
  • SPEEDRUN: each trial (a level, a boss, the whole game) has its own ranking by time.
  • CHALLENGE: a challenge with set rules (one weapon, one constraint), from start to finish, each with its own ranking by time. Challenges are not certified.
  • Mass Run: live races, dozens of players on the same level from the same start. Each game has its rating per format; the top ten of each game’s permanent Mass Speedrun leaderboard score points. Races are not certified.

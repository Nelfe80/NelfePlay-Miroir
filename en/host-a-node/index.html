Host a NelfePlay node

Leaderboards, records and replays stay online even when the main server goes down, thanks to partner servers around the world. Have a server? Join the network.

Why nodes

Always online

If the main server goes down, visitors are sent to a mirror: leaderboards, game pages, player cards and records stay available.

Closer to players

Each mirror serves its region: pages and replays arrive faster.

Nothing personal

A node only receives what is already public. No email address, no password, no account data ever leaves the main server.

What your server can do

wwwN.nelfeplay.com

Public site mirror

Serves a verified copy of the public site. Needs a public address and ports 80 and 443.

replayN.nelfeplay.com

Replays

Stores and serves replays, each checked by its size and SHA-256 fingerprint.

no port to open

Computing

Takes verifiable jobs: compression, fingerprints, video rendering.

scoringN.nelfeplay.com

Score relay

Receives scores from cabinets and forwards them to the main server. By agreement, for hosts we already know.

What you need

  • ✓64-bit Linux (x64 or ARM64), with Docker or a direct install
  • ✓For a mirror: a fixed public address and ports 80 and 443
  • ✓Disk space depending on the role (a few gigabytes for a mirror)
  • ✓Automatic updates turned on
  • ✓A NelfePlay account with a verified email address

The charter

  • ✓Never change anything the node serves.
  • ✓Keep the copy up to date: the node syncs on its own, do not stop it.
  • ✓Do not exploit or resell the data passing through.
  • ✓Keep connection logs to a minimum, and no longer than required.
  • ✓Give notice before leaving the network.

How it works

  1. 01

    Application

    Fill in the form below.

  2. 02

    Review

    The team reviews your offer and gets back to you. Only approved hosts join the network.

  3. 03

    Enrollment code

    You receive a single-use code, tied to your NelfePlay account.

  4. 04

    Installation

    One command, or the Docker image, with your code. The node tests itself.

  5. 05

    Going live

    Your node gets its name (for example www3.nelfeplay.com) and its certificate, then joins the network with a small weight that grows with its reliability. The server list stays private: you see it from “My servers”, like the other approved hosts.

✓

A verifiable mirror

Every version of the site is signed by NelfePlay, and the node refuses any altered copy. Mirrors check each other: every hour, each one reads two others, drawn at random, just as a visitor would, and compares what they serve with the signed version. NelfePlay verifies every reported difference; a mirror that alters what it serves is removed from the network.

# NelfePlay, copie du site public

Copie automatique du site public de nelfeplay.com (pages, classements certifiés de `/records`), servie
par GitHub Pages sous https://miroir.nelfeplay.com. Le serveur la régénère ; elle reste lisible s'il est
indisponible. Ne pas modifier à la main : chaque passage remplace le contenu.

Chaque version porte un manifeste (`nelfeplay-site.manifest.json` : chemin, taille et SHA-256 de chaque
fichier) signé par NelfePlay (`nelfeplay-site.manifest.sig`, ECDSA P-256).

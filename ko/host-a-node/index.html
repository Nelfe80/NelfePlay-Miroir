필요한 것

  • ✓64비트 Linux(x64 또는 ARM64), Docker 또는 직접 설치

  • ✓역할에 따른 디스크 공간(미러는 수 GB)
  • ✓자동 업데이트 사용

  • ✓노드가 제공하는 내용을 절대 수정하지 않습니다.
  • ✓사본을 최신으로 유지합니다: 노드는 스스로 동기화하니 막지 마세요.
  • ✓통과하는 데이터를 이용하거나 판매하지 않습니다.
  • ✓접속 기록은 최소한으로, 요구된 기간을 넘겨 보관하지 않습니다.
  • ✓네트워크를 떠나기 전에 미리 알립니다.
